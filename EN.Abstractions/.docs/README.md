
# EntityNexus.Abstractions

Версия: 10.7.12

Кратко
------
EntityNexus.Abstractions — набор абстракций доменной модели для фреймворка EntityNexus DSL. Библиотека предоставляет интерфейсы и базовые типы для реализации Code-First подхода на базе Entity Framework Core.

Что включает пакет
------------------
- Интерфейсы доменных сущностей
- Общие DTO/конфигурации для проекта
- Контракты для контекста базы данных и сервисов домена

Быстрый старт
-------------
1. Установка через NuGet (собранный пакет публикуется при сборке проекта):

   dotnet add package ova.EntityNexus.Abstractions --version 10.7.12

2. Пример использования

```csharp
using EntityNexus.Abstractions;

public class MyEntity : IEntity
{
	public Guid Id { get; set; }
	public string Name { get; set; } = string.Empty;
}

// Регистрация в DI и реализация DbContext ожидаются в проекте-реализации
```

Архитектура и назначение
------------------------
EN.Abstractions не содержит реализаций хранилища данных: она описывает контракты, которые реализуются в других пакетах (например, EntityNexus.Core или приложении пользователя). Это позволяет отделить доменную модель от конкретной ORM-реализации и облегчить тестирование.

Рекомендуемые практики
----------------------
- Реализуйте контекст БД (DbContext) в отдельном проекте и используйте миграции EF Core там же.
- Не изменяйте публичные интерфейсы без версии мажорного обновления — это может нарушить совместимость.
