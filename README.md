# EntityNexus

## Ограничения EnityNexus Free

### Навигационные свойства сущностей

1. Формирование навигационных свойств для связей вида N:N не предусмотрено.
2. В автоматическом режиме формируется только одно навигационное родительское свойство. Следствием этого является формирование ограниченной древовидной структуры графа связей, тем не менее, достаточной для большинства простых приложений.
   Ограничение обусловлено невозможностью более чем однократного наследования сущностью одного и того же универсального интерфейса (IParent <TEntiy>).
   При усложнении структуры до полного графа, содержащего сущности с двумя и родительскими связями, в  последние следует добавить второе и последующие родительские навигационные свойства вручную в реализации. 
3. Дочерние связи формируются автоматически без ограничений.
